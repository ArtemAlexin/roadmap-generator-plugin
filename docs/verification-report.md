## Границы проверки

Установка в конкретный агентский клиент и публикация в каталоге не выполнялись. Проверено подключение реального MCP-клиента через SDK, а не интерфейс конкретного приложения. Формы вопросов и запуск отдельного проверяющего зависят от возможностей агента-хоста; предусмотрен режим вопросов в чате.

Демонстрация и её записи проверки источников — синтетические тестовые данные, не готовая исследованная учебная программа. Источники будущих roadmap должен фактически исследовать агент. Сервер проверяет структуру доказательств и арифметику, но не способен доказать истинность утверждения о проверке источника или независимость контекста модели. Прохождение тестов не доказывает полноту произвольной программы обучения и полное соответствие любого будущего контента WCAG.

Содержательный проходной результат требует реальной отдельной проверки. Без неё экспорт явно маркируется как предварительный. API-вызовов моделей, распределения между моделями и удалённого HTTP-сервера в этой версии нет.

## Дополнение: нативный OpenCode

Добавлен адаптер OpenCode V2 с регистрацией MCP, навыка и команды `/roadmap`, корневой `opencode.json` для автоподключения и генератор внешней конфигурации `config opencode`. В текущем установленном релизе 2.2.5 фактически проверен ключ `plugin`; новый документированный ключ `plugins` доступен через `--modern`.

Шесть новых модульных/интеграционных тестов адаптера проверяют регистрации, очистку, конфликты, параметры, сохранение пользовательского запроса/вложений, конфигурацию и реальный запуск MCP. Итоговый `npm run test:all` из целевого проекта: **32/32 успешно** — 19 модульных/MCP/адаптерных и 13 браузерных тестов.

Реальный smoke-тест на установленном OpenCode 2.2.5 подтвердил: плагин `roadmap-generator` имеет статус `active`, навык `roadmap` и команда `/roadmap` зарегистрированы, MCP-сервер `roadmap` имеет статус `connected`. Использовалась изолированная конфигурация XDG и временный сервер на localhost; пользовательские настройки не менялись, вызовов моделей не было. Дополнительно **успешно выполнен** тест `npm run test:opencode -- --self` из целевого проекта: подтверждено автоподключение через его корневой `opencode.json`.

Фактическая генерация учебной программы моделью в OpenCode в этот smoke-тест не входит. Общий генератор HTML/PDF не изменялся.


## Исправления интерактивного опроса и выбора сайта

Локальная рабочая версия после тега 0.0.1: полный прогон из целевого проекта **36/36 успешно** (23 модульных/MCP/адаптерных и 13 браузерных). Smoke-тест нативного плагина выполнен на установленном OpenCode **2.2.6**: active, навык и команда зарегистрированы, MCP connected. Если хост вообще не предоставляет интерактивного ввода, инструкция требует явно объяснить ограничение; сервер не может создать отсутствующий интерфейс.
